# 三国杀 · 标准版（网页版 / 局域网对战）

浏览器打开即玩的《三国杀》身份局实现。古风界面，支持单机 + AI、局域网开黑、自由点将 / 点身份、DIY 武将。

## 快速开始

```bash
npm install
npm start
```

- **本机访问**：http://localhost:3000
- **局域网开黑**：启动后终端会打印局域网 IP（如 `http://192.168.x.x:3000`），好友浏览器直接打开即可加入同一房间

> macOS 上首次运行若 npm 缓存权限报错，可执行：
> `npm install --cache /tmp/npm-cache`

## 玩法

1. 主页输入昵称 → **创建房间**（或加入列表中的房间）
2. 房间内：点击空位坐下 / 点「添加电脑」补位（房主可操作）
3. 房主设置：人数（4~8）、随机选将 / 自由点将、候选数量、是否点身份、是否启用 DIY 武将
4. 可选 **点身份**（开局优先按你的选择分配）
5. 房主 **开始游戏** → 进入选将 → 开始对局
6. 出牌阶段：点击手牌选择，操作条会弹出可用的使用方式（含转化技如武圣/龙胆/奇袭/国色）；主动技能显示为按钮；点击其他玩家面板选择目标
7. 响应阶段（被杀/南蛮/万箭等）：右侧提示条会弹出「闪 / 杀 / 桃 / 无懈可击 / 八卦阵」按钮

### 核心机制
- 身份局（主/忠/反/内），4~8 人身份分配
- 完整回合流程：准备（观星/洛神）→ 判定（乐不思蜀/闪电/八卦阵）→ 摸牌（含突袭/裸衣/英姿）→ 出牌 → 弃牌（克己）→ 结束（闭月）
- 距离计算（±1 马、马术、麒麟弓 / 顺手 / 奇才 / 雌雄）
- 伤害结算：防具（仁王盾/八卦阵/青釭剑）、武器特效（贯石斧 / 青龙偃月刀 / 方天画戟 / 丈八蛇矛 / 寒冰剑 / 雌雄双股剑 / 铁骑 / 麒麟弓）
- 濒死求桃（含救援 / 急救 / 激将）
- 奖惩（杀反贼摸三、主杀忠弃牌）
- 无懈可击连锁（含集智摸牌）
- 所有转化技：武圣 / 龙胆 / 倾国 / 急救 / 奇袭 / 国色 / 丈八蛇矛
- 主公技（激将 / 救援）
- 重洗牌堆、断线 AI 托管、断线重连

### 模式与扩展功能
- 多种游戏模式：身份局 / 1v1 / 3v3 / 国战 / 斗地主
- 自定义房间规则（血量加成 / 手牌上限 / 回合数限制 / AOE 开关等）、10 种内置胜利条件、规则预设分享码、禁将 / 禁牌
- 观战模式（30 秒防作弊延迟快照、只读界面、弹幕聊天）
- 录像回放（JSON / 文本导出、对局分析、分享链接）
- DIY 技能（可视化 DSL 编辑器）与 DIY 卡牌（图片上传），均已接入引擎（牌堆构建与技能执行生效）
- 记牌器、皮肤 / 头像框系统、成就系统、游戏速度 / 回合计时器

### AI

智能 AI 引擎，具备以下能力：

- **身份推理**：根据行为（攻击/保护主公、AOE 使用、治疗模式）推断隐藏身份
- **威胁评估**：综合距离、手牌、装备、血量、历史伤害计算威胁度
- **智能目标选择**：优先击杀脆弱敌人、濒死目标、高威胁角色
- **资源管理**：根据局势保留关键牌，低血量优先自救
- **技能协同**：识别Combo（苦肉+桃、仁德+回血、离间+决斗）
- **角色化策略**：不同身份有不同武将优先级和打法风格

### DIY 武将
主页点「DIY 武将」进入编辑器：自定义名字、称号、势力、体力（3~5）、性别，从技能库选 1~2 个技能，可上传头像（自动生成古风占位头像）。创建后自动出现在可选武将池中（房主可开关是否启用）。

## 操作说明

- **手牌**：点击选中，再次点击取消；悬停上移
- **距离**：自己头像旁显示与其他玩家的距离；「顺手牵羊」等会依法限制可选目标
- **技能**：出牌阶段下方技能按钮可发动；被动/锁定技为虚线框，不可点击（悬浮查看说明）
- **聊天**：房间大厅右侧可文字聊天
- **离开**：游戏中离开自动由 AI 托管本局；结束后房主可「返回大厅」重开

## 音效与配音

- **实时音效**：全部音效由 Web Audio API 实时合成，无需加载音频文件，零额外体积
  - 杀（挥击）、闪（躲避）、桃（回复音）、受伤（打击）、回复（闪烁音）、阵亡（低沉铜锣）、判定（翻牌）、摸牌（洗牌）、装备（金属撞击）、胜利号角、失败音、出牌提示等
- **武将配音**：随包语音覆盖标准 25 名武将的选将 / 阵亡 / 技能语音（共 89 个 WAV），由 macOS `say` 语音 Tingting（中文）预生成；`npm run gen-voices` 脚本现已遍历全部 70 名武将（重新生成会补齐全部语音）
  - 选中武将时播报「{武将名}，{称号}」
  - 武将阵亡时播报「{武将名}，呃啊……」
  - 主动技能（仁德 / 制衡 / 苦肉 / 反间 / 结姻 / 青囊 / 离间 / 激将）触发时播报技能名
  - 其他平台无预生成文件时自动回退到浏览器 Web Speech API 合成中文语音
- **控制**：右上角 🔊 按钮点击静音 / 取消静音；滑块调节 0~100% 音量（状态自动保存）
- **出牌动画与视觉特效**：卡牌飞向目标带拖尾粒子、伤害/回复数字浮起、躲避「闪」字弹出、装备金色光环、南蛮/万箭 AOE 扫荡、判定中央翻牌、死亡崩塌+屏震、阶段横幅、回合金色光晕、胜负全屏结算动画
- 全部特效支持 `prefers-reduced-motion` 自动降级

## 快捷键

出牌阶段支持全键盘操作（按钮上标有快捷键提示，按 H 显示帮助）：

| 快捷键 | 功能 |
|---|---|
| `1` - `0` | 选择第 1~10 张手牌（手牌左上角显示数字） |
| `Enter` / `Space` | 确定 / 打出 |
| `Esc` / `⌫` | 取消选择 |
| `Q` / `E` | 切换出牌方式（如杀 ↔ 武圣·红牌当杀） |
| `Tab` / `←` `→` | 切换目标 |
| `X` / `End` | 结束出牌 |
| `F1` - `F8` | 发动第 1~8 个主动技能 |
| `M` | 静音 / 开启 |
| `↑` / `↓` | 音量增减 10% |
| `H` / `?` | 显示 / 关闭快捷键帮助 |

- 帮助面板：右上角浮窗，显示全部快捷键
- 输入框内按键不触发快捷键（避免打字冲突）
- 模态弹窗打开时快捷键暂停
- 音频数据：`public/assets/audio/voices/<武将id>/*.wav` + `phrases/` 短语音（约 5.4MB）

```bash
npm run simulate    # 无头模拟 10 局（全 AI，验证引擎稳定性）
npm run gen-avatars # 重新生成程序化剪影占位头像 SVG
npm run test:fast   # 快速测试套件（数据完整性 / 拼点，无需服务器）
npm test            # 完整测试套件（含浏览器 CDP 测试）
```

额外浏览器端 E2E 测试位于 `test/`（`test/e2e.js` 需先启动服务器；`test/browser-*.js` 由 CDP 驱动无头浏览器，其中 `browser-check.js` 驱动的是 Edge）。

## 替换/自定义头像

`public/assets/avatars/` 现内置 70 名武将的真实 JPG 头像。把 JPG / PNG 放到 `public/assets/avatars/<武将id>.jpg|png`（如 `caocao.jpg`）即可覆盖对应武将头像；界面按 **JPG → PNG → SVG** 顺序加载，全部缺失时回退到程序化生成的剪影 SVG 占位头像。DIY 武将可在创建时上传。

## 技术栈

- **服务端**：Node.js + Express + ws（WebSocket），零编译，npm 即开
- **前端**：原生 HTML / CSS / JS（无框架，无构建步骤）
- 通信：WebSocket 自定义 JSON 协议（断线重连 + AI 托管）
