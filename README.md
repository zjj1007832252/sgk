# 三国杀 · 标准版（网页版 / 局域网对战）

浏览器打开即玩的《三国杀》身份局实现。古风界面，支持单机 + AI、局域网开黑、自由点将 / 点身份、DIY 武将。

## 快速开始

```bash
npm install
npm start
```

- **本机访问**：http://localhost:3000
- **局域网开黑**：启动后终端会打印局域网 IP（如 `http://192.168.x.x:3000`），好友浏览器直接打开即可加入同一房间

> macOS 上首次运行若 npm 缓存权限报错，可执行：
> `npm install --cache /tmp/npm-cache`

## 玩法

1. 主页输入昵称 → **创建房间**（或加入列表中的房间）
2. 房间内：点击空位坐下 / 点「添加电脑」补位（房主可操作）
3. 房主设置：人数（4~8）、随机选将 / 自由点将、候选数量、是否点身份、是否启用 DIY 武将
4. 可选 **点身份**（开局优先按你的选择分配）
5. 房主 **开始游戏** → 进入选将 → 开始对局
6. 出牌阶段：点击手牌选择，操作条会弹出可用的使用方式（含转化技如武圣/龙胆/奇袭/国色）；主动技能显示为按钮；点击其他玩家面板选择目标
7. 响应阶段（被杀/南蛮/万箭等）：右侧提示条会弹出「闪 / 杀 / 桃 / 无懈可击 / 八卦阵」按钮

### 核心机制
- 身份局（主/忠/反/内），4~8 人身份分配
- 完整回合流程：准备（观星/洛神）→ 判定（乐不思蜀/闪电/八卦阵）→ 摸牌（含突袭/裸衣/英姿）→ 出牌 → 弃牌（克己）→ 结束（闭月）
- 距离计算（±1 马、马术、麒麟弓 / 顺手 / 奇才 / 雌雄）
- 伤害结算：防具（仁王盾/八卦阵/青釭剑）、武器特效（贯石斧 / 青龙偃月刀 / 方天画戟 / 丈八蛇矛 / 寒冰剑 / 雌雄双股剑 / 铁骑 / 麒麟弓）
- 濒死求桃（含救援 / 急救 / 激将）
- 奖惩（杀反贼摸三、主杀忠弃牌）
- 无懈可击连锁（含集智摸牌）
- 所有转化技：武圣 / 龙胆 / 倾国 / 急救 / 奇袭 / 国色 / 丈八蛇矛
- 主公技（激将 / 救援）
- 重洗牌堆、断线 AI 托管、断线重连

### AI
简单启发式 AI，会按身份（反贼集火主公、忠臣护卫等）出杀闪桃、用锦囊、发动技能。适合单人练手 / 填满座位；后续可逐步强化。

### DIY 武将
主页点「DIY 武将」进入编辑器：自定义名字、称号、势力、体力（3~5）、性别，从技能库选 1~2 个技能，可上传头像（自动生成古风占位头像）。创建后自动出现在可选武将池中（房主可开关是否启用）。

## 操作说明

- **手牌**：点击选中，再次点击取消；悬停上移
- **距离**：自己头像旁显示与其他玩家的距离；「顺手牵羊」等会依法限制可选目标
- **技能**：出牌阶段下方技能按钮可发动；被动/锁定技为虚线框，不可点击（悬浮查看说明）
- **聊天**：房间大厅右侧可文字聊天
- **离开**：游戏中离开自动由 AI 托管本局；结束后房主可「返回大厅」重开

额外浏览器端 E2E 测试位于 `test/`（需启动服务器后运行 `test/e2e.js`、`test/browser-play.js`）。

## 替换/自定义头像

把 PNG 图片放到 `public/assets/avatars/<武将id>.png`（如 `caocao.png`）即可覆盖对应武将的 SVG 占位头像；界面会优先加载 PNG，失败时回退到 SVG。DIY 武将可在创建时上传。

## 技术栈

- **服务端**：Node.js + Express + ws（WebSocket），零编译，npm 即开
- **前端**：原生 HTML / CSS / JS（无框架，无构建步骤）
- 通信：WebSocket 自定义 JSON 协议（断线重连 + AI 托管）
